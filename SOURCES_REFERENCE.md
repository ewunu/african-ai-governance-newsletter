## Setting Up Google Alerts (Supplementary)

For sources without RSS, set up Google Alerts:

1. Go to: `https://www.google.com/alerts`
2. Create alerts for:
   - `"AI governance" Africa`
   - `"artificial intelligence" "African Union"`
   - `"AI regulation" Kenya OR Nigeria OR "South Africa"`
   - `"AI ethics" Africa`
   - `"responsible AI" developing countries`
3. Set frequency to: "As-it-happens" or "Once a day"
4. Delivery to: Your email (you can then review for newsletter)

## Adding New Sources

When you find a new relevant source:

1. Test the RSS feed works: `https://validator.w3.org/feed/`
2. Add to `sources.json` in the `rss_feeds` array:
```json
{
  "name": "Source Name",
  "url": "https://example.com/feed/",
  "region": "Pan-African",
  "focus": "AI governance"
}
```
3. Commit and push to GitHub
4. The next scheduled run will include the new source
